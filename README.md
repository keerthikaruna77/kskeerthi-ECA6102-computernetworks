This project implements Inter-VLAN Routing using two separate VLANs to enable communication between different network segments. VLAN 10 is designed in a star topology, while VLAN 20 is implemented in a bus topology. The network is configured with appropriate switch ports, VLAN assignments, and router-based inter-VLAN routing to ensure secure and efficient communication. End-to-end connectivity is verified through successful ping tests between devices in different VLANs. This project demonstrates VLAN segmentation, logical network design, and inter-VLAN communication using Cisco Packet Tracer
