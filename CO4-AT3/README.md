**Enterprise Security Architecture Using Cisco Packet Tracer**

**Project Description**

This project presents the design and simulation of a comprehensive enterprise network security architecture using Cisco Packet Tracer. The main objective is to demonstrate how security mechanisms such as firewall access control, intrusion detection/prevention concepts, and VPN connectivity can be integrated to protect an enterprise network.

The simulated network consists of an untrusted network, a firewall router, a secured internal network, a web server, and a branch network connected through a second router. Cisco routers and switches are used to establish communication between the different network segments.

**Security Features Implemented**

Firewall: An Extended Access Control List (ACL) is configured on the firewall router to control incoming network traffic.

Access Control: Authorized traffic such as ICMP and HTTP is permitted, while unwanted services such as Telnet and other unauthorized traffic are restricted.

Network Segmentation: The network is divided into untrusted, secured, and branch sections to improve security.

VPN Architecture: Two routers are connected to represent a secure VPN communication path between the enterprise and branch network.

IDS/IPS Concept: The architecture includes intrusion detection/prevention as part of the overall security design for identifying and controlling suspicious traffic.

Security Testing: Connectivity tests and restricted-traffic scenarios are used to evaluate the effectiveness of the implemented security policies.

Cisco Packet Tracer

Testing and Evaluation

The network was tested using ping and service-access scenarios to verify authorized communication. Firewall ACL rules were also checked using router CLI commands to verify that the configured security policies were active.

The simulation demonstrates how a firewall can permit legitimate communication while restricting unauthorized traffic, providing a basic enterprise security architecture suitable for network security analysis and testing.

**Conclusion**

The project demonstrates the practical implementation of an enterprise security architecture in Cisco Packet Tracer. By integrating firewall-based access control, IDS/IPS security concepts, network segmentation, and VPN connectivity, the simulation provides a controlled environment for evaluating authorized communication, restricted traffic, and potential attack scenarios.
