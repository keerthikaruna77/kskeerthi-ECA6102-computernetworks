Digital Forensics:

Digital forensics involves the collection and examination of information from digital devices, and it is generally employed in the case of a cyber incident or when suspicious activity is detected. Computers, mobile phones, hard disks, pen drives and other types of storage devices may hold useful evidence. The primary aim of digital forensics is to determine what took place during an incident and to understand the activities connected with it. The key stages include evidence acquisition, preservation, analysis and reporting.

Evidence Acquisition:

The first stage in digital forensics is evidence acquisition. At this stage, the investigator determines which device or storage medium might hold useful evidence. It is possible to gather important files, system logs, browser history, emails and other information. A forensic copy of the original data is generally made for examination. This allows the investigator to work on the copy without altering the original evidence.

When collecting evidence the investigator must be careful. The device should not be used unless necessary since it might generate new data and could cause some of the old information to be altered. It is also necessary to record details such as the date, the time, the name of the device and the person who collected the evidence.

Evidence Preservation:

The evidence must be kept safely after it has been collected, since digital evidence is easy to alter, delete or damage. The original evidence should therefore be stored in a secure location and only authorized people should handle it.

Hash values are also helpful in the preservation of evidence since a hash value is similar to a digital fingerprint of the evidence and if the hash value before and after the investigation is the same this shows that the evidence has not been altered. Proper preservation makes the evidence more trustworthy.

Evidence Analysis:

Evidence analysis involves looking at the data that has been gathered. The investigator examines various kinds of information in order to identify any suspicious activities. Useful details can be obtained from files, system logs, the timestamps, browser history and user activities.

It is also possible to check deleted files if necessary. The investigator might obtain information regarding login attempts, changes to files, unusual activities or unauthorised access. Different kinds of evidence can be compared in order to understand the sequence of events. For instance, login records and the timestamps on files can be used to determine when a suspicious activity took place.

The analysis has to be carried out with care since not all files or activities are connected with the incident. The investigator must concentrate on the relevant information and note the significant findings.

Evidence Reporting

Once the analysis has been carried out, the investigator draws up a forensic report. This report should set out the evidence that was gathered, the way in which it was preserved and the results of the investigation. It is also possible to include information about the tools and methods employed.

Screenshots, hash values and all other relevant information may be included in the report and the results have to be explained clearly enough for someone else to understand the investigation that has been carried out. The report should finish with a conclusion drawn from the evidence gathered.

Importance of Digital Forensics:

Digital forensics is useful in a great many cases within the field of cyber security and can be used to investigate incidents such as malware attacks, unauthorized access, data theft, phishing attacks and other suspicious activities. It enables an organization to discover the reason why an incident occurred and to locate key evidence.

It also contributes to better security following an incident; by examining the evidence the organization is able to identify the weakness in the system and act to prevent a similar incident in the future.

Conclusion

Digital forensics offers a suitable way of dealing with digital evidence, the process mainly consisting of evidence acquisition, preservation, analysis and reporting. When these steps are carried out properly, the investigation becomes more reliable. It enables investigators to understand cyber incidents and supplies useful information for improving the security of an organization.
